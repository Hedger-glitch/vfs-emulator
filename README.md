# VFS Emulator (Вариант 20)

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой в памяти. Практическая работа по курсу «Конфигурационное управление».

## Возможности

- Интерактивный REPL с приглашением `<имя_vfs>> `.
- Парсер командной строки с поддержкой кавычек.
- Обработка ошибок (неизвестная команда, неверные аргументы, ошибки ФС).
- Виртуальная файловая система в памяти (не трогает диск).
- Загрузка VFS из XML-файла, содержимое файлов в base64.
- Стартовый скрипт: выполнение команд из файла с имитацией диалога.

## Команды

- `ls [путь]` — содержимое каталога или имя файла.
- `cd [путь]` — сменить текущий каталог (`..`, `.`, `/` поддерживаются).
- `rev файл` — строки файла в обратном порядке символов.
- `uniq файл` — убрать подряд идущие одинаковые строки.
- `head [-N] файл` — первые N строк (по умолчанию 10).
- `mv источник цель` — переместить или переименовать.
- `chmod режим путь...` — изменить права (восьмеричное число).
- `exit` — выход.

## Параметры командной строки

- `--vfs путь` — путь к XML-файлу VFS.
- `--script путь` — стартовый скрипт (если задан, REPL не запускается).
- `--name имя` — имя VFS для приглашения (по умолчанию `myvfs`).
