# VFS Emulator (Вариант 20)

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой (VFS) в памяти. Разработан в рамках практической работы по курсу «Конфигурационное управление».

## Возможности

На текущий момент реализовано:
- Интерактивный REPL (Read-Eval-Print Loop) с приглашением вида `<имя_vfs>> `.
- Парсер командной строки с поддержкой одинарных и двойных кавычек.
- Обработка ошибок: неизвестная команда, синтаксическая ошибка.
- Команды-заглушки: `ls`, `cd` (печатают имя и аргументы).
- Команда `exit` для выхода.

## Требования

- Python 3.10 или выше
- pytest (для запуска тестов)
